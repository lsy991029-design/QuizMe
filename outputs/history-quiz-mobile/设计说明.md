# 与古人同频 · 移动端网页视觉设计

设计日期：2026-10-18

## 设计范围

沿用已选定的第一种视觉主题，完成开始测试、情境答题、人物结果、结果分享四个页面的移动端高保真设计图。本交付为视觉设计稿，尚未实现答题计算、图片保存、链接复制或线上发布。

## 视觉与尺寸

- 设计基准：390 × 844 CSS 像素；设计图输出为 1008 × 2176 像素，比例近似一致。
- 视觉主题：米白宣纸底色、水墨人物与山水、朱砂红主要操作、墨色标题。
- 布局：单列竖屏；实施时使用弹性布局适配 360–430 CSS 像素宽的手机。
- 操作：主要按钮高度不小于 48 CSS 像素；选项整行可点击；底部预留设备安全区域。
- 内容：不要求用户具备历史知识；测评为趣味性格探索，不作为专业心理测评。

## 页面与交互规划

1. 开始测试：说明主题、题量与预计耗时，点击“开启我的历史剧本”进入答题。
2. 情境答题：单题单选；展示进度、选中状态与上一题、下一题；未选择时不可进入下一题；返回上一题时保留已有选择。
3. 人物结果：展示匹配人物、人物插画、核心特质与相似性解读；示例人物为苏轼；支持重新测试与生成分享卡。
4. 结果分享：展示可保存的人物卡，提供保存图片与复制测试链接操作。人物卡内容应与当前结果一致；分享地址须使用实际发布后的网址。

## 实施注意事项

- 设计稿中的文字与按钮在正式网页中应实现为可访问的 HTML 元素，不应将整张设计图作为可交互网页。
- 设计图由图像生成工具制作，正式实施时需校对文字、字号和触控尺寸。
- 人物结果应由已确定的题目与计分规则生成；本轮未设计完整题库及匹配算法。
- 保存图片应使用实际生成的人物海报；复制链接应使用实际可访问的线上测试地址。
