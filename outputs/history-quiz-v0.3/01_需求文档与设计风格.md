# 与古人同频：需求文档与设计风格

版本：v0.3 评审稿

## 2. 产品定位、用户与场景假设

定位：通过普通生活情境中的选择，匹配一位性格倾向相近的中国历史人物，给出可理解的依据和可分享的身份卡片。产品属于娱乐性探索，不提供心理诊断，也不测量真实历史人物的人格。

| 角色 | 触发场景 | 关键任务 | 期望结果 | 证据状态 |
| --- | --- | --- | --- | --- |
| 自测访客 | 碎片时间主动进入或看到主题推广 | 完成测试，理解结果 | 知道匹配到谁、为什么 | 待试答验证 |
| 分享者 | 完成测试后愿意表达个人趣味身份 | 保存卡片、生成公开链接 | 内容完整、适合传播 | 待试答验证 |
| 分享访客 | 收到朋友的图片或链接 | 看懂对方结果，决定是否自测 | 不误以为对方结果是自己的 | 待试答验证 |

“人物认同感能够促进分享”“无需登录能降低开始成本”“结果解释能增加认可”均为待验证假设。首版通过开始率、完成率、分享操作和访客转化观察价值，不先设缺乏依据的商业目标。

关键体验触点：开始时说明题量；答题时保留进度；出结果时先给身份再解释；分享时保持内容一致并明确公开范围。用户对人物的认识与本产品设定可能不同，结果页须保留形象依据及趣味测试说明。

## 3. 范围与取舍

首版包含：匿名测试、24 题单选、六维画像、100 种确定性结果、结果解释、图片保存、公开摘要链接、当前浏览器恢复、异常重试、必要的行为统计。

首版不包含：登录、付费解锁、排行榜、匹配稀有度、好友关系测试、多主题题库、AI 实时生成结果及运营后台。人物数据先以版本化配置维护，上线前通过编辑审核发布；不因未建设后台而跳过审核。

优先级按核心任务依赖排序：答题与正确匹配、完整结果、两种分享渠道均为首版必需；额外动画、主题换肤等后续评估。100 位人物的体例与内容完整性属于首版范围，不能用少量人物加随机姓名替代。

## 4. 信息架构与主流程

主流程：开始页 → 24 题答题 → 计算结果 → 结果页 → 分享页。

分享页采用同一模板的两种模式：本人模式显示预览、保存图片、复制链接、返回结果；公开访客模式显示公开卡片与“测测我的历史同频人物”。公开访客开始自己的测试后，建立新的本地会话，不复用分享者答案。

不设置与任务无关的多级导航。页内帮助、趣味测试说明及隐私说明按需展开，不要求用户在开测前阅读长篇介绍。

## 5. 页面与交互需求

### P01 开始测试

页面目标：理解主题并开始或继续测试。首屏包含产品名、主标题、说明、24 题与 100 位人物信息，以及一个主操作。

建议文案：主标题“如果生在古代，你会与谁同频？”；说明“24 道情境选择，遇见与你倾向相近的中国历史人物。”；主按钮“开始测试”。预计用时在真人试答完成后按实际结果填写，当前不显示固定分钟数。

有兼容的本地草稿时，主按钮显示“继续测试”，次按钮“重新开始”。有已答内容时重新开始需说明将清除本轮进度；取消保留原状态。已完成结果和已生成分享快照不随新一轮草稿被清除。

状态：初始化、可开始、有草稿、配置加载失败。配置失败时展示原因与“重新加载”，不创建空题测试。

### P02 答题

顶部为返回、题号“01 / 24”和进度条；中部为情境题与四个单选项；底部为“上一题”和“下一题”，最后一题改为“查看结果”。第一题不提供无效的上一题。

初始无默认选项。选中后在当前题显示选择状态，用户点击下一题才前进。未选时主按钮不可用，邻近显示“请选择一个选项”；选择状态同时使用边框、标记和控件语义，不能只靠颜色。

上一题保留答案。每次选择更新本地草稿；保存失败时提示“当前设备未能保存进度，关闭页面后可能需要重新作答”，当前会话仍可继续。点击返回开始页不清除草稿。题目变化后焦点移动到题目标题，屏幕阅读器能识别题号与选中状态。

进度条按已回答题数 / 24 计算，题号表示当前题位置。提交前再次校验完整性；有缺答则定位到首个未答题。计算中按钮显示“正在生成结果”，禁止重复提交，不人为延长等待。失败保留答案，展示可重试操作。

### P03 结果

信息顺序：结果身份 → 一句话类型 → 三个标签 → 基于本次答案的动态解读 → 六维倾向 → 可参考的优势与提醒 → 人物历史关联 → 趣味测试说明。

主操作为“分享我的结果”，次操作为“重新测试”。人物姓名与类型首屏可见。六维使用带文字的横向刻度，详情按需阅读。文字说明不能仅存在于图中。

固定人物摘要明确标注为本产品中的人物形象；动态解读只能依据用户答案。用户位于均衡区间时不强行赋予强偏好。结果不展示科学相似率、人格优劣、未验证人数或稀有度。并列结果按固定编号决胜并提示有多位相近画像。

直接打开本人结果地址时须有有效结果快照，否则回到开始页并说明尚无可用结果。配置加载失败提供重试，不随机展示人物。重新测试创建新会话，旧分享保持原结果。

### P04 分享

本人模式：卡片预览、保存图片、复制链接、返回结果。卡片展示产品名、人物名、类型、三个标签、精简说明、入口二维码/网址及趣味测试说明；不放原始答案或用户个人信息。

图片建议输出 1080 × 1440px，需验证实际渠道预览与扫码效果。生成前等待字体加载；字体不可用则使用经过验证的系统回退重排。使用真实二维码编码库生成实际 URL，生成后解码核对。不将概念图、未发布地址或占位码作为可用分享入口。

保存图片：先生成，再按浏览器能力下载或打开可长按保存的图片；网页只在能力允许时说明已下载，不宣称图片已经进入系统相册。生成失败保留结果，支持重试。

复制链接：生成对应公开摘要快照并取得可访问地址后再复制；复制权限失败提供可选中的完整链接。服务失败不回退为虚假链接。用户取消系统分享不记为分享成功。

公开访客模式：不显示“我的结果”及编辑操作；明确“这是一份分享结果”，主按钮进入访客自己的测试。失效链接提供“结果暂时无法查看”与“开始我的测试”。卡片链接可被持有者访问，创建前以简短说明告知其公开性质。

## 6. 匹配与内容体系

采用六维、每维四题的建议方案。每题为 0—3 分；每轴累计 0—12。人物画像采用同一整数尺度，六维等权，以欧氏距离平方选最近人物，并列时使用稳定编号。完整题目、分值、字段及解释规则见《03_24道题与评分规则》。

100 位人物使用有史料依据的对象，不采用花木兰等仅凭文学传说形成的角色；老子、孙武等生平与文本研究存在争议的对象，在内容中明确限制。暂按清末民初以前的历史人物编制，具体时间边界属于待评审项。

每位人物包含唯一编号、时代领域、类型、六维画像、三个标签、形象摘要、优势、提醒、历史关联、分享短句、画像依据及资料线索。图片与公开页面使用同一版本内容。史料候选尚未逐篇核验，上线前需补齐可靠出处与审核记录，不将影视或小说情节当作史实。

## 7. 数据、版本和访问边界

建议无需登录，不收集姓名、生日、手机号或头像。答题草稿在当前浏览器本地保存；不承诺跨设备、无痕模式或主动清除存储后的恢复。草稿建议保存 7 天，期限是待确认建议；过期后说明需重新开始，不默默沿用旧答案。

草稿包含会话编号、内容版本、题号答案、当前题号、更新时间。已开始的会话固定版本。若旧版本不可用，说明无法继续并提供重新开始，不将旧答案映射到新题库。

完成时形成版本化结果快照。本地答案和公开分享分离；分享服务仅接收允许公开的结果、标签、动态解读分档及内容版本，不接收原始答案。公开接口只返回白名单字段，不暴露编辑资料、答案和内部计分。服务端校验版本及人物存在性，文本从可信版本配置取得，不把客户端任意文本直接发布。

公开链接使用不可顺序枚举的标识。同一结果重复创建应返回已有快照或通过幂等标识避免重复写入。公开链接保存期限、删除方式、是否需要仅本人持有的撤销凭证及具体存储服务待技术评审确定，在明确之前不承诺永久有效。技术方案不得将删除凭证放入公开链接。

## 8. 视觉风格与设计规范建议

方向：当代人文杂志风。关键词为人文、清爽、克制、轻复古、可收藏。历史感由中文衬线标题、编辑式排版与颜色建立，不依赖插画、人物肖像、水墨山水或装饰贴图。

| 项目 | 建议规范 |
| --- | --- |
| 背景 | 暖纸白 #F6F3EC；不叠加影响阅读的仿旧纹理 |
| 内容底色 | #FFFDFA |
| 主文字 | 墨黑 #252722 |
| 辅助文字 | 灰绿 #64675F，真实字号下检查对比度 |
| 品牌强调 | 朱红 #A63D32，用于主操作、选中状态及重点身份 |
| 分隔线 | #DED9CF，仅用于辅助分组，不独自表达必要状态 |
| 字体 | 标题与人物名采用有授权的中文衬线字体；正文使用无衬线系统字体 |
| 移动基准 | 390px，设计与验收覆盖 360—430px；桌面居中阅读，不增加无关模块 |
| 字号 | 主标题建议 36—44px；题目 22—26px；正文与选项 16—18px |
| 间距 | 采用 4/8px 基础级差；页面边距建议 20—24px，分组留白优先于重边框 |
| 操作 | 触控目标不低于 48px；按钮与选项有焦点、选中、禁用、加载状态 |
| 圆角与阴影 | 建议 8—12px 轻圆角；弱阴影或无阴影，避免所有内容都装入卡片 |
| 动效 | 150—250ms 的状态切换；支持减少动态效果，不以动画延迟结果 |

开始页采用杂志封面式大标题；答题页集中于一题一组选择；结果页以人物名建立识别度；分享页采用统一竖版编辑卡片。100 位人物共用视觉模板，以文案与标签形成差异，不依赖 100 套配色。

正式视觉稿前需选择具体视觉方向；本稿为文字规范，不等同于用户已选中某张设计图。后续若进入 Product Design 视觉探索，生成三种无插画视觉方案后再选择和实施。

## 9. 异常与恢复

| 场景 | 状态与处理 | 恢复路径 |
| --- | --- | --- |
| 首次配置失败 | 不创建空会话，不进入答题 | 重新加载 |
| 本地存储不可用 | 当前内存会话可继续，提示不能保证恢复 | 保持页面完成，或确认后重新开始 |
| 缺答或非法答案 | 不计算结果，不随机补选 | 定位缺答题或重新载入当前题配置 |
| 重复点击提交 | 维持一个计算/提交状态 | 复用同一结果，不创建重复记录 |
| 分享接口超时 | 不宣称成功，保留结果与幂等标识 | 查询已有快照或安全重试 |
| 图片或字体失败 | 不清空结果，不输出残缺卡片 | 重试或使用经过验证的回退字体 |
| 下载或复制不支持 | 明确浏览器限制 | 可长按图片或手动复制链接 |
| 内容版本不存在 | 不套用当前版本 | 说明不可用，开始新一轮 |
| 公开链接失效 | 不显示他人的随机替代结果 | 开始自己的测试 |

## 10. 非功能、埋点与验证

兼容目标建议为近期 iOS Safari、Android Chrome、桌面 Chrome/Safari/Edge 及微信内置浏览器，最终版本矩阵上线前确定。检查底部安全区域、字号放大、键盘导航、屏幕阅读器单选语义、减少动态效果及文字对比度。所有文本作为可访问文字实现，不把整张设计稿当网页。

性能验证使用加载、出结果和生成分享图等真实任务；具体 P95 阈值、设备、网络条件与测量环境需技术评审确定，当前不填未经验证的“秒开”承诺。计算可本地运行；断网时若配置已加载，允许继续作答与查看结果，链接创建说明需联网。

| 指标/事件 | 口径 |
| --- | --- |
| 开始率 | 观察期内开始新测试的匿名会话数 / 可开始页曝光会话数 |
| 完成率 | 同一开始批次最终获得有效结果的会话数 / 该批次开始会话数；排除尚在观察期内的会话 |
| 题目流失 | 同一版本中进入某题但观察期内未继续完成的会话，按题号分析 |
| 分享操作率 | 点击图片保存或链接复制的结果会话数 / 结果曝光会话数，按渠道拆分 |
| 操作完成 | 分开记录图片生成完成、下载动作、复制成功；不能等同发送给好友 |
| 访客转化 | 带分享来源进入后开始新测试的会话数 / 有效分享访客会话数 |

建议事件包括 landing_view、quiz_start、quiz_resume、question_view、quiz_complete、share_preview、poster_generated、copy_link_success、share_landing_view。记录版本、匿名会话和成功/失败原因；常规分析不记录原始答案。观察窗口、匿名会话有效期、统计平台与数据保存期限上线前确认。

## 11. 验收标准

| 编号 | 前置与操作 | 可观察结果 |
| --- | --- | --- |
| AC01 | 未登录进入开始页，点击开始 | 进入第 1 题，24 题可依次完成 |
| AC02 | 未选择，尝试继续 | 无法前进，显示选择提示；不自动作答 |
| AC03 | 选择后返回上一题并修改 | 原答案回显，后续计算使用修改值 |
| AC04 | 存储可用且版本有效时刷新 | 恢复本轮答案及当前位置 |
| AC05 | 存储不可用 | 当前作答可继续，有进度无法保存的说明 |
| AC06 | 对同一版本提交相同答案两次 | 人物编号、分档与解释一致 |
| AC07 | 按每位人物可达样例作答 | 100 位分别匹配到对应编号，不依赖随机选择 |
| AC08 | 全选同一字母 | 六轴均衡，动态解释不夸大单侧倾向 |
| AC09 | 构造最小距离并列的答案 | 按固定编号选择，标明有多位相近画像 |
| AC10 | 重新开始或开始新一轮 | 本轮草稿按确认清除，旧分享快照保持原结果 |
| AC11 | 生成图片并打开对应链接 | 人物、标签、摘要和版本一致，二维码可解码至实际地址 |
| AC12 | 访客打开公开链接 | 仅见公开字段，不能读取原始答案或编辑资料；可开始自己的测试 |
| AC13 | 图片、复制或链接创建失败 | 保留结果，失败提示与替代操作符合实际能力 |
| AC14 | 在目标移动宽度、字体放大时使用 | 无横向溢出、关键文字截断或底部按钮遮挡选项 |
| AC15 | 检查四页及分享卡片 | 不含插画、人物肖像和水墨山水装饰，文字与功能元素可访问 |

本轮脚本仅完成结构与匹配规则检查；网页、服务、设备相关验收均未实施。具体已检查范围见《04_内容与匹配检查报告》。

## 12. 风险、待确认与下一阶段条件

| 待确认事项 | 当前建议/状态 | 影响与阶段 |
