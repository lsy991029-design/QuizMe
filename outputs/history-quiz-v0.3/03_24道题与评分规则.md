# 与古人同频：24 道题与评分规则

版本：0.3.0-draft；状态：题库评审稿；日期：2026-10-18。

## 一、编写及作答规则

24 题全部必答，每题单选、4 个选项。每个维度 4 题，每题只计入一个维度。各维度按六题一轮交错出现。无正确答案、无默认选项、无倒计时。用户选中后点击下一题；上一题可以修改。预计耗时待试答后确定。

选择最接近日常习惯的答案，不要求每次都完全如此。题目文案及评分标签须在上线前通过认知访谈与试答，不能将形式覆盖视为测量有效性。面向用户不展示轴名与分值，不展示历史人物提示。

## 三、计分与匹配契约

1. 答案按 Q01—Q24 顺序提交，每项只能是 A、B、C、D。缺失、重复题号、未知题号、未知选项、非字符串值均视为非法；客户端和服务端使用相同版本校验。参考脚本使用固定顺序数组，接口采用题号对象时另行校验重复与未知项。
2. 每题只计入配置中的一个维度，分值为 0、1、2、3。每维四题相加，形成 0—12 的整数原始分。六轴顺序固定为 decision / social / change / expression / focus / organization。
3. 六个维度等权。对用户向量 u 和人物画像 p，计算 distance² = Σ(u[i] − p[i])²。按距离平方升序排列；不在匹配前四舍五入，不引入随机数、热门加权或结果配额。
4. 最小距离并列时，按稳定人物编号 H001—H100 的升序选取；这是本版本的技术决胜规则，不代表人物排名。保留并列状态，用简短说明提示本次有多位画像同样接近，不展示确定性过强的相似度。
5. 人物画像均在可实现的整数网格中，且彼此不同。每位人物至少有一组合法答案令用户向量等于该画像，距离为零且唯一最小。可达样例用于验证规则，不应作为诱导用户答出某人物的公开题解。
6. 修改答案、题库、画像、计分或并列规则之一，都可能改变结果。题库版本、画像版本和匹配规则作为同一内容版本固定；已完成结果和分享内容按原版本展示。
7. 不将 100 种结果强制均分，不声称 24 题足以科学识别 100 种真实人格。题库认知访谈和真人试答后才能评估区分度及稳定性。

## 四、结果解释与展示规则

- 0—4 分：更靠近该轴低分端；5—7 分：两端较接近；8—12 分：更靠近高分端。该分档是暂定展示规则，真人试答后可按版本调整。
- 面向用户展示两端名称及当前位置，不显示内部原始分、科学相似率、人格稀有度或未经证实的用户排名。刻度只是本次选择的可视化。
- 解释始终以用户真实答案为准。建议句式：“在决策方式上，本次选择更靠近‘审慎权衡’一端。”中间区间写“两端倾向较为接近，尚未呈现明确偏向。”
- 人物卡片的固定摘要描述本产品设定的人物形象，不直接断言用户具备该人物全部特征；优势和提醒作为参考阅读，不作为测量结论。
- 若用户与人物在某轴同属低分端或同属高分端，可以说“这一选择方向与该人物画像相近”；一方在中间区间或方向相反时，不把该轴写作共同特质。没有明确同向轴时，仅说明按六轴综合距离得到该人物。
- 全部选择同一字母时，每维均为 6 分。系统仍按固定规则得到结果，动态解读应显示均衡倾向，不指责用户作答，也不编造强偏好。
- 页面不提供“精准度”“诊断”“天生就是”等表述。说明：“基于本次选择的趣味匹配，不是人格定论。”

## 五、内容对象与字段

| 对象 | 主要字段 | 必填与约束 |
| --- | --- | --- |
| 维度 | id / name / low / high | 六个稳定 id，两端均为中性描述 |
| 题目 | id / dimension / title / options | 题号唯一，选项四个且分值覆盖 0—3；每维四题 |
| 人物 | id / name / era / field / typeTitle / profile | 人物及编号唯一，六轴各 0—12 整数，画像互不相同 |
| 人物内容 | tags / summary / strength / caution / historicalContext / shareText | 三标签；摘要与历史关联分开；不伪造名言 |
| 编辑记录 | profileRationale / sourceCandidates / reviewStatus | 画像为编辑设定；候选资料上线前须核验并记录版本和审核人 |
| 结果快照 | contentVersion / resultId / displayBands / createdAt | 与原始答案分开；分享仅含经过筛选的公开摘要 |

## 六、试答与修订计划

首轮建议邀请 12—20 位非专业用户试答，记录每题理解、实际耗时、犹豫原因、选项是否存在明显优劣、结果认同和修改一题后的结果变化。该人数是可用性试答建议，不足以建立心理测量效度，也不是已完成研究。

需要优先观察的混淆：表达外显不等于社交意愿；果断程度不等于计划习惯；探索偏好不等于随机应变；独立自主不等于不关心他人。

若题意出现系统性误解，先改题与选项，再评估人物画像。不能仅为提高认同率而随意把用户改配给热门人物。修改后升版本，重建内容并运行检查；真实试答结论另行记录，不覆盖原报告。

## 七、参考工具与局限

scripts/matcher.py 为本轮内容评审的确定性参考实现；scripts/audit.py 检查题库结构、输入、可达性及合成分布。它们未接入现有网页，不提供线上链接或图片服务。脚本通过只能证明已覆盖的规则，不代表历史资料已审核、量表有效或产品可上线。
