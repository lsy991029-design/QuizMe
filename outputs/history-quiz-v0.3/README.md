日期：2026-10-18。对应用户已确认的性格倾向匹配、中国历史人物、暂名「与古人同频」、24 题 / 100 种结果、图片与链接分享，以及无插画要求。

## 阅读顺序

1. [需求文档与设计风格](01_需求文档与设计风格.md)：范围、四页交互、分享、异常、数据、视觉与验收。
2. [100 位人物库与画像](02_100位人物库与画像.md)：总表、全部人物的结果文案、六维设定和候选核验资料。
3. [24 道题与评分规则](03_24道题与评分规则.md)：完整题目、选项、分值、匹配公式及动态解释。
4. [内容与匹配检查报告](04_内容与匹配检查报告.md)：已验证规则、合成样本分布与尚未完成的验证。

## 可复用内容

- `data/people.json`：100 位人物与六维定义。
- `data/questions.json`：24 题与显式选项分值。
- `data/reachability-witnesses.json`：每位人物的一组合法 24 题答案。
- `data/audit-report.json`：结构、可达性、合成分布及数据哈希。
- `scripts/build_content.py`：人物和题库编辑源；重新生成 JSON 与对应 Markdown。
- `scripts/scoring_rules.md`：题库文档的评分与解释章节编辑源。
- `scripts/matcher.py`：确定性参考匹配，可输入 24 个 A—D 字母预览结果。
- `scripts/audit.py`：验证并重建检查报告及可达样例。

在本目录运行：

```sh
python3 scripts/build_content.py
python3 scripts/audit.py
python3 scripts/matcher.py ABCDABCDABCDABCDABCDABCD
```

脚本使用 Python 标准库，无需安装依赖。修改人物或题库后，必须按顺序重新生成、检查，并同步升级内容版本；本轮仍属于评审草稿。
